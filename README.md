## Description
**NetPractice** is a practical, interactive learning project to teach the fundamental networking concepts through progressively levels. it’s useful for essential network administration skills that are needed in real-world system administration or networking jobs.

## Instructions
This project is different from other projects as it is not code based. therefore, to test we have to:

- **1.** Download the *net_practice.1.9.tgz* from the project page or the evaluation sheet.

- **2.** Unzip the .tgz file and extract it in any folder of your choice.
```console
user@42:~$ tar -xvzf net_practice.1.9.tgz -C /path/to/folder/you/need
```
- **3.** Go inside the folder and run the run.sh file:
```console
user@42:~$ cd ./net_practice.1.9/net_practice
user@42:~$ bash run.sh
```
- In addition, the evaluated has to finish level 6 to 10 in under 15 minute.
- Extra : check the evaluation repository for the ten training levels config files.
